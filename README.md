## 🔐 Secrets

Ce dépôt est **privé**. Les secrets sont dans `.env` (ajouté au `.gitignore`).

## 🚀 Configuration

1. Copier `.env.example` → `.env`
2. Remplir les valeurs sécurisées
3. Lancer l'agent : `python agent_n8n.py`
